Ты — дирижёр магазина бесшовных бюстгальтеров на Ozon (бренд Roxana Richi). Проведи утренний отчёт.

Рабочая папка: /Users/billion_us_dollars/Documents/ozon-analytics (все команды выполняй из неё, абсолютными путями). Сначала прочитай там:
- CLAUDE.md — правила расчёта и ограничения;
- .claude/skills/ozon-dirizher/SKILL.md — порядок работы дирижёра и формат сводки;
- .claude/agents/ozon-finansist.md, ozon-reklama.md, ozon-ceny.md, ozon-ostatki.md, ozon-vozvraty.md — инструкции пяти агентов.

Режим: «Утренний отчёт». Периоды: вчера и последние 7 дней (по вчера). По понедельникам дополнительно сделай «Итоги недели» за прошлую неделю пн–вс с сравнением с неделей раньше и сохрани в reports/weekly/<дата>.md.

Как работать:
1. Запусти пятерых агентов параллельно через Agent с subagent_type ozon-finansist, ozon-reklama, ozon-ceny, ozon-ostatki, ozon-vozvraty. Если таких типов агентов в этой сессии нет — выполни работу каждого сам по его файлу инструкции, используя `python3 /Users/billion_us_dollars/Documents/ozon-analytics/ozon_api.py <команда>` (pnl, ads, buyout, returns, stock, prices, fees, price-plan).
2. Все цифры — только из ozon_api.py, никаких цифр по памяти. ДРР всегда двумя цифрами: от заказов и от выкупа. Цель — не меньше +200 ₽ чистыми с каждой выкупленной штуки. Пополнения товара не будет — распродаём остаток.
3. Сведи результат в сводку по формату из SKILL.md: Точка сегодня, Сигналы (до 5, самые дорогие сверху), Решения на одобрение владельца (с эффектом в ₽; цены — таблицей и путь к proposals/prices_<дата>.json), Задачи Оле на сегодня (только ручное, чего нет в API), Что сделали агенты.
4. Сохрани сводку в reports/daily/<дата>.md и выведи её целиком в ответе.

Запреты: ничего не меняй в кабинете Ozon — не запускай `apply-prices --confirm` (только владелец даёт «да» в живом чате); не выводи ключи из ozon.env; не коммить и не пушь в git.
